# LGU Real — Municipality of Real, Quezon Province

Official government website with full admin panel.

## Structure
- `public/index.html` — Public website
- `admin/index.html` — Admin panel (staff only, login required)
- `supabase/migrations/` — Database schema
- `vercel.json` — Hosting configuration

## Default Admin Login
- URL: `/admin`
- Username: `admin`
- Password: `Admin@Real2026!` *(change immediately after first login)*

## Deployment
Connected to Vercel — pushes to `main` auto-deploy.
